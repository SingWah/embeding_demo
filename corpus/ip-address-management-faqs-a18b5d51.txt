公网IP和私网IP是否独立，能指定或增加IP吗？
公网IP以NAT模式映射到私网IP。您可以指定辅助私网IP，也可以通过多IP方式增加IP。
如何将实例的固定公网IP更换为其它EIP？
如果您在购买云服务器时选择了固定带宽，并且已经购买了新EIP，您可以按以下步骤操作：
方式一
将固定带宽转换为按量带宽，具体操作请参见公网带宽计费。
将固定公网IP转换为EIP，具体操作请参见专有网络ECS实例的固定公网IP转换为EIP。
解绑转换得到的EIP，具体操作请参见解绑EIP。
绑定新的EIP，具体操作请参见绑定ECS实例。
方式二：
在OOS管理控制台，通过ACS-ECS-ConvertsPublicIPToNewEIPByInstanceId运维模板，将一台实例的公网IP转化为其它弹性公网IP。华东1（杭州）地域请访问ACS-ECS-ConvertsPublicIPToNewEIPByInstanceId，您可以单击链接后，在OOS管理控制台顶部菜单栏自行更换地域。
ECS实例转移和更换公网IP地址有什么限制？
转移和更换ECS实例的公网IP地址有以下限制：
不支持公网IP及EIP跨账号转移。
如果实例没有分配公网IP，您可以为实例绑定EIP。您可以通过绑定新的EIP更换公网IP。
如果实例已经分配了公网IP：
实例创建后6小时内，允许更换公网IP地址，最多可以更换3次。具体操作，请参见更换公网IP地址。
通过将公网IP转换为EIP的方式更换IP。具体操作，请参见固定公网IP转为弹性公网IP。
如何查询ECS实例的IP地址？
Linux实例
通过ifconfig查看网卡信息。您可以查看IP地址、子网掩码、网关、DNS、MAC地址等信息。
Windows实例
在命令窗口，通过ipconfig /all查看网卡信息。您可以查看IP地址、子网掩码、网关、DNS、MAC地址等信息。
更多信息，请参见IP地址。
如何禁用ECS实例的公网网卡？
Linux实例
通过ifconfig查看ECS实例网卡名称。
通过ifdown禁用网卡。假设网卡名称为eth1，则输入ifdown eth1。
说明
您也可以通过ifup命令重新启动网卡。假设网卡名称为eth1，则输入ifup eth1。
Windows实例
在命令窗口，通过ipconfig查看网卡信息。
打开，禁用网卡。

具体操作，请参见IPv6通信。
创建实例后，我可以更换公网IP（IPv4）地址吗？
实例创建六小时内，您可以更换公网IP地址。详细步骤，请参见更换公网IP地址。
超过六小时后，根据实例的网络类型有不同区别。
支持将公网IP转换成弹性公网EIP。详细步骤请参见固定公网IP转为弹性公网IP。
为什么在ECS管理控制台上，我看不到更换公网IP选项？
实例创建六小时内：您可以直接在控制台上更换公网IP。
实例创建六小时后：不支持直接更换公网IP地址，因此无法看到更换公网IP选项。
更多信息请参见固定公网IP。
除了更换公网IP地址，我还可以更换私网IP地址吗？
可以。详细步骤，请参见主私网IP。
如果在创建实例时未分配公网IP（IPv4）地址，实例创建成功后怎么获得公网IP地址？
申请和绑定弹性公网IP。具体操作，请参见申请EIP。
变更实例公网带宽，从而分配一个固定公网IP地址。包年包月实例的更多信息，请参见升降配方式概述，按量付费实例的更多信息，请参见按量付费实例修改带宽。
按量付费 ECS 实例的公网 IP 是如何分配的？释放后能否重新获得同一个 IP？
按量付费 ECS 实例创建时，系统从公网 IP 地址池中随机分配一个公网 IP 地址，该地址不固定。释放实例后，该 IP 地址将被回收至地址池。再次创建实例时，系统会重新从地址池中随机分配 IP 地址，不保证获得与之前相同的 IP 地址。如需使用固定公网 IP，建议申请并绑定弹性公网 IP（EIP）。

如何屏蔽来自指定地域或海外的访问？
ECS安全组仅支持基于IP地址或CIDR网段的访问控制规则，不支持按地域维度进行访问控制。如需按地域封禁访问，根据业务类型选择以下方案：
网站服务：接入Web应用防火墙，使用区域封禁功能封禁特定地域的访问。
非网站服务：使用配置内网访问互联网的流量管控策略的区域选择功能。
ECS主网卡能否解绑并绑定给其他ECS实例？
不释放ECS实例的情况下，ECS 实例的主网卡无法解绑并绑定到其他实例。
如需ECS实例不释放的前提下，将主网卡的私网 IP 分配给另一台 ECS 实例，可参考以下步骤：
关停持有该私网 IP 的源实例。
修改源实例主网卡的私网 IP，将其更改为同一网段下另一个未使用的 IP，以释放原 IP。
关停目标实例。
修改目标实例主网卡的私网 IP，将其设置为原实例的私网 IP。
释放ECS实例默认删除关联的弹性网卡。可以在释放实例时设置保留弹性网卡，并绑定至新实例。请参考释放实例时保留弹性网卡。
