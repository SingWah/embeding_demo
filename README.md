# embeding-demo（成品包）

双击 `explorer.html` 就能用：**不需要 Python、不装依赖、不联网**。这里是把「语料」和「网页」放在一起的成品包，展示 **用户输入 → Token → Token 映射到高维向量 → 用高维向量把映射关系展示出来** 这条链路。

## 目录里有什么

| 路径 | 内容 |
| --- | --- |
| `explorer.html` | 单文件交互式 3D 页（2.45 MB）：3,456 词 × 100 维向量全量内嵌，最近邻、向量类比、语料原文命中都在浏览器里现算 |
| `corpus/` | 训练语料：260 篇阿里云官网 ECS 手册原文 `.txt`（每个文件头两行是标题与来源 URL）+ `manifest.tsv` 抓取清单 + `fetch-summary.json` 抓取统计 |
| `figs/` | 训练时产出的 6 张静态图：PCA 全量散点、查询词邻域、邻居相似度、类比平行四边形、逐轮 loss、方差与模长 |

## 怎么玩

1. 拖空白 = 旋转视角，Shift+拖 = 平移，滚轮 = 缩放，双击空白 = 取消选中。
2. 单击某个点或它的标签 → 选中词标红加粗，它的最近邻按名次标橙加粗并连线；**拖住红色选中词，整组关联词会一起走**（被拖开的词在原投影位留空心圈和虚线，只是临时布局，向量与坐标没变），「拖拽复位」还原。
3. 左下「4. 语料原文」卡片：选中一个词后，列出它真实出现在哪几篇文档、各命中多少次，点标题直接打开 `corpus/` 里的 `.txt` 原文；展开下面的清单可以翻完全部 260 篇。
4. 中间「2. 向量类比 A − B + C」：默认 `地域 − 可用区 + 华东`，算出来 top1 是 **北京**（cos 0.570）。
5. 词表只收了出现 ≥5 次的 3,456 个词，图上点不到的低频词请用左侧搜索框。

## 这些数字从哪来（都可核对）

- 语料：260 篇 / 2,050,582 字符，抓取页数、空页、重复、限流统计见 `corpus/fetch-summary.json`。
- 分词：jieba + 51 词 ECS 自定义词典（安全组 / 可用区 / 密钥对 / 专有网络…，不加词典这些词会被切成「安全 + 组」）→ 319,998 token，词表覆盖 97.4%。
- 训练：skip-gram + 负采样，dim=100、window=5、neg=5、10 轮，2,714,985 条训练对，loss 1.370 → 1.341（Apple MPS，88 s）。
- 语料原文索引：导出时用同一套 jieba + 同一份自定义词典扫全部 260 篇（不是抽样），3,456 / 3,456 个词都有命中记录。
- 页面里的「离线产物对照」表来自 Python 落盘的 `stage3_*.tsv`；前端实时重算与它逐条一致，5 个查询词 top5 顺序全同、最大偏差 4.4e-4（只是 TSV 存 6 位小数的舍入）。

## 已知边界（不藏着）

- 3D 底图是 PCA 前 3 个主成分，本例合计只解释约 8.3% 方差——**屏幕远近是低维投影，不等于语义远近**，排序一律用 100 维余弦。
- 词表只三千多词、语料只有一份产品手册：类比残差 1.1~2.4，页面对每条类比都标了「结构松散，仅参考」。
- 想重新训练或改词表：生成这套成品的脚本（`word2vec_demo.py`、`fetch_ecs_docs.py`、`export_w2v_html.py`、`userdict-ecs.txt`）不在本仓库里，本仓库只放成品包；页面里所有数字都能对着 `corpus/` 原文和 `figs/` 落盘产物复核。
- `corpus/` 是从 help.aliyun.com 公开文档页抓取的原文纯文本（每个文件保留来源 URL），仅用于本教学 demo 复现数字，不是阿里云官方发布内容。
