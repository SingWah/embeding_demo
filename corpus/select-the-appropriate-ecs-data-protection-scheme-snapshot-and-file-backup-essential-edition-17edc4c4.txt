# 如何选择文件备份和快照
> https://help.aliyun.com/zh/ecs/user-guide/select-the-appropriate-ecs-data-protection-scheme-snapshot-and-file-backup-essential-edition

为应对误删除或业务变更等风险，阿里云提供了文件备份与快照两种核心数据保护能力，可根据具体的业务场景、恢复颗粒度、运维复杂度和成本预算，作出合适的选择。
功能概述
ECS文件备份基础版可每日自动备份ECS实例文件，并支持文件级粒度的数据恢复。
文件备份基础版：文件系统级别（File System Level），通过在ECS实例中安装客户端进行备份。
快照：块存储级别（Block Level），云盘数据在某个时刻的完整拷贝，无需安装客户端，保证数据的一致性。
功能对比
文件备份与快照是保护ECS实例数据的两大核心手段。为防止数据丢失，建议至少选择并配置一种方案。
对比维度
文件备份基础版
快照 (Snapshot)
备份与恢复粒度
文件粒度的备份与恢复：可直接恢复单个文件或目录到原路径或其他ECS。
对于不支持创建快照的ESSD PL-X云盘、本地盘及弹性临时盘建议使用文件备份基础版进行数据保护。
云盘粒度的备份与恢复：可通过回滚原云盘或创建新云盘来恢复整个磁盘的数据。
计费方式
按块存储容量计费：每个用户的阿里云（主账号）及其下的RAM用户在全地域共享100 GiB免费额度。按ECS实例挂载的块存储（云盘、本地盘及弹性临时盘）总容量计费，首次备份成功后开始计费，与实际备份的数据量无关，成本清晰可预期。计费详情，请参考文件备份基础版的权益说明。
按快照容量计费。快照容量与存储的数据量和变化量相关，采用“首次全量，后续增量”备份机制，首次创建为全量快照，后续仅备份自上次快照以来发生变化的数据块。计费详情，请参考快照计费。
备份策略
默认每日备份一次，保留30天且至少保留一个版本，生成的最新备份版本会被默认保留（可手动关闭），不会因保留时间到期而删除。
可设置自动快照策略进行周期性备份，支持自定义保留时长（1～65536天），并可在创建后手动延长保留时间。
一个云盘支持绑定多个自动快照策略，可根据不同应用或业务需求，定制不同的备份频率和保留策略。
典型应用场景
网站或应用数据保护： 需要对代码、配置文件、用户上传内容等文件数据，进行精细化备份与恢复。
简化恢复操作：仅需在web控制台进行恢复操作，降低误操作风险和人力投入成本。
防范勒索病毒：利用备份锁定功能保护备份数据不被篡改或删除。
业务快速部署： 需要快速批量部署，创建环境一致的ECS实例，可创建快照并使用快照制作自定义镜像是最高效的方式。
高危操作前数据保护： 在更换操作系统、扩容云盘等高危操作前，手动创建快照，立即备份数据。
基础数据长期备份： 无需文件级恢复、仅需对单云盘的数据实现周期性备份或希望长期保留备份数据。
恢复单个文件的流程
当需要恢复单个文件时，文件备份基础版支持直接通过控制台恢复特定的文件，比快照操作更便捷，可以降低误操作风险。
