# 弹性计算 Agent Credits 计费规则
> https://help.aliyun.com/zh/ecs/user-guide/ecagent-billing-instructions

弹性计算 Agent 以 Credits 作为统一计量单位，免费开通、按量付费，支持预付费资源包抵扣，两种方式可叠加使用。
Credits 说明
Credits（积分）是弹性计算 Agent 统一计量与结算单位。用户在使用会话、定时任务等场景下产生的模型资源消耗会折算成 Credits 进行计费。不同复杂度的任务对应不同的 Credits 消耗量。

消费逻辑
当存在多个有效的资源包时，优先抵扣先到期的资源包。
资源包消耗完或者全部到期后，按 0.05 元/Credit 进行按量付费，出账周期为 5 分钟。
Agent 消费遵循超限策略：无限额按量模式下任务不受限；限额按量模式下达到月度上限后任务自动暂停。
超限策略
弹性计算 Agent 提供两种超限策略，帮助您在成本管控与业务连续性之间灵活选择。可在控制台用量与限额页面单击修改切换策略。

购买说明
需使用弹性计算 Agent 服务所属的阿里云账号或 RAM 用户进行订单相关操作。
建议使用阿里云主账号下单购买资源包。
如需使用 RAM 用户下单，请授予以下权限策略：
AliyunBSSOrderAccess：支付订单权限。
弹性计算 Agent 完整访问权限系统策略或自定义等价权限策略，详情参见权限配置。
常见问题
Credits 消耗是否与账单一致？
是的。Credits 消耗数据以「用量与限额」页面为准，账单中会按 5 分钟出账周期汇总实际扣费。
Credit 资源包到期后未用完的 Credits 会如何处理？
资源包到期后，未使用的 Credits 将被清零，不可续期使用。建议根据历史用量合理选择资源包容量。
是否有 Credits 免费额度？
新用户开通后可能获得一定量的赠送 Credits，具体额度以控制台「用量与限额」页面显示为准。
RAM 用户购买 Credit 资源包时提示权限不足怎么办？
购买 Credit 资源包需要 AliyunBSSOrderAccess（支付订单权限）和弹性计算 Agent 相关权限。建议使用主账号购买，或联系主账号管理员为 RAM 用户添加相应权限。
