# 3 分钟上手弹性计算 Agent
> https://help.aliyun.com/zh/ecs/user-guide/ecagent-quick-start

通过一次控制台会话与一个定时任务的完整体验，快速上手弹性计算 Agent 的智能问答、资源查询、异常诊断、健康巡检四大核心能力，并了解定时任务扩展场景与 Credits 用量查看方式。
前提条件
已注册阿里云账号并完成实名认证。首次访问 弹性计算 Agent 控制台 时，勾选服务协议并单击「立即开通」即可开通服务，无需订阅、无预付门槛。
如需以 RAM 用户身份使用，请先由主账号完成权限授权。详见权限配置。
建议账号内至少存在 1 台 ECS 实例，便于体验资源查询、健康巡检等能力。
发起首次会话
首页展示四大能力入口卡片：智能问答、资源查询、异常诊断、健康巡检。您可以直接点击任意预置提问快速体验。
示例 1：智能问答
在首页预置提问中点击「ECS 按量付费和包年包月的区别是什么？」。
Agent 自动检索知识库，返回结构化对比表格。
预计消耗 2 Credits。
示例 2：资源查询
在首页预置提问中点击「查询杭州地域 ECS 实例信息」，或在输入框中输入自然语言查询。
Agent 调用资源查询工具，返回实例列表（ID、规格、状态、地域）。
预计消耗 5 ~ 10 Credits（取决于实例数量）。
示例 3：异常诊断
在首页预置提问中点击「ECS 远程无法连接帮我诊断」。
预置提问内容自动填入输入框，您可以在此基础上补充具体实例 ID，然后点击发送。
Agent 委托子 Agent 进行诊断，返回结构化诊断报告（问题定位、修复建议）。
预计消耗 10 ~ 20 Credits（单实例）。
示例 4：健康巡检
在首页预置提问中点击「巡检当前账号下 GPU 实例」。
Agent 调用巡检工具，扫描账号下所有 GPU 实例的运行状态、GPU 硬件健康、驱动版本、监控指标等，并返回结构化巡检报告（覆盖实例数、异常项、修复建议）。
预计消耗 20 ~ 50 Credits（取决于实例数量，单次一次性巡检）。
说明
若需周期性自动巡检（如每天定时执行、结果推送到 IM 群），请使用定时任务能力，参见下方创建定时任务。
创建定时任务（可选）
如果您希望周期性自动执行运维检查（如每天定时巡检 GPU 实例），可以基于官方模版创建定时任务。以下示例演示基础配置流程（不含 IM 推送）：
在弹性计算 Agent 控制台左侧导航栏，单击 定时任务，切换到 任务模版 页签。
选择一个内置模版（如 GPU 资源健康巡检），单击 创建任务。
在任务表单中填写任务名称、选择执行周期（如「每天 09:00」）。此处保持 开启 IM 通道 开关关闭，即不将执行结果推送到 IM 群，仅在控制台查看。
保存任务后，切换到 已配置任务 页签，可看到任务卡片展示「每天 09:00 自动触发」。单击 立即执行 手动触发一次验证。
在 执行记录 页签查看历次执行结果和详细报告。
说明
如需将定时任务执行结果自动推送到钉钉、飞书或企微群，请先创建 IM 渠道，并在任务表单中打开「开启 IM 通道」开关，详见配置 IM 渠道。
查看 Credits 用量
在弹性计算 Agent 控制台左下角，点击 设置 > 用量与限额，即可查看当前账号的总 Credits、已消耗 Credits、剩余额度与消耗趋势。详细字段与出账周期说明请参见计费方式。
后续步骤
配置 IM 渠道：将 Agent 能力和定时任务结果推送延伸到钉钉、飞书、企微运维群。
权限配置：为 RAM 用户配置合适的权限策略。
计费方式：了解 Credits 计费规则、资源包购买。
