# ECS被安全锁定对API调用的影响
> https://help.aliyun.com/zh/ecs/developer-reference/api-behavior-when-an-instance-is-locked-for-security-reasons

当您的ECS实例因存在安全违规内容（包括挖矿、欺诈、有害信息等）而触发安全事件后，ECS实例将被锁定。本文将为您介绍ECS实例被锁定后对API调用的影响。
如何判断实例已被安全锁定
通过调用DescribeInstances接口，若返回参数中的OperationLocks包含了LockReason: security，则表示ECS实例已被安全锁定。
登录ECS管理控制台，在左侧导航栏单击事件 > 实例安全事件，若存在实例安全事件，则表示存在ECS实例已被安全锁定。在实例安全事件中存在实例被安全封禁事件，表示其中的ECS实例已被安全锁定。
在 实例被安全封禁事件 页签下，表格显示事件名称为 实例因安全违规被封禁，事件等级为 严重，事件状态为 待处理，事件原因为"违反《互联网信息服务管理办法》第十五条规定"。
