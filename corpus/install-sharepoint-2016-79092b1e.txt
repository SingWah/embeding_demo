# 安装SharePoint 2016
> https://help.aliyun.com/zh/ecs/user-guide/install-sharepoint-2016

SharePoint Server 2016是由Microsoft开发的企业协作平台和内容管理系统，可以共享和管理内容、知识和应用程序，加强团队合作、快速查找信息并在整个组织内实现无缝协作。本文介绍如何在Windows Server系统的ECS实例上安装SharePoint Server 2016。

步骤二：安装SQL Server
前往SQL Server下载页，选择下载合适的SQL Server。
本文中由于是测试环境，使用的是SQL Server 2022 Express版本。
说明
Express版本默认不支持TCP/IP协议，需要手动开启。
Express版本默认（可能）没有管理控制台，需要单独安装SQL管理工具。
建议使用企业版数据库生成系统，Express版本相对企业版本缺少部分功能。
双击SQL Server安装包，选择安装类型为自定义(C)。
选择SQL Server 2022下载位置，单击安装(I)。
在SQL Server 安装中心界面，单击全新 SQL Server 独立安装或向现有安装添加功能。
在适用于SQL Server 的Azure扩展步骤中，取消勾选适用于SQL Server 的Azure扩展，然后单击下一步(N)。
在功能选择步骤中，保持默认，然后单击下一步(N)。
在实例配置步骤中，选中默认实例(D)，然后单击下一步(N)。
在数据库引擎配置步骤中，选中Windows 身份验证模式(W)，单击添加当前用户(C)，然后单击下一步(N)。
根据界面提示，完成安装SQL Server。
步骤三：安装配置SharePoint Server 2016
安装SharePoint 2016必备组件
前往SharePoint Server 2016下载页，下载SharePoint镜像文件。
将Microsoft SharePoint Server 2016镜像文件解压，然后双击准备工具的可执行文件prerequisiteinstaller.exe。
在产品准备工具界面，单击下一页(N)。
产品准备工具将安装配置以下必备组件：Web 服务器(IIS)角色、Microsoft SQL Server 2012 Native Client、Microsoft ODBC Driver 11 for SQL Server、Microsoft Sync Framework Runtime v1.0 SP1 (x64)、Windows Server AppFabric、Microsoft Identity Extensions、Microsoft Information Protection and Control Client 2.1、Microsoft WCF Data Services 5.6、Microsoft .NET Framework 4.6。
选中我接受许可协议的条款，单击下一页(N)。
当显示安装完成界面时，说明组件已安装，请单击完成重启系统。
安装完成界面显示各组件状态：部分组件（如 Microsoft SQL Server 2012 Native Client、Microsoft ODBC Driver 11 for SQL Server、Microsoft Sync Framework Runtime v1.0 SP1 (x64)）安装成功，部分组件（如 Windows Server AppFabric、Microsoft Identity Extensions 等）因需要重启而跳过安装。单击 完成 重启系统后将继续安装剩余组件。
重启后，当显示安装完成界面时，说明已安装完成。
安装SharePoint Server 2016
打开Microsoft SharePoint Server 2016镜像文件，双击安装文件setup.exe，开始安装Microsoft SharePoint Server 2016。
输入产品密钥，单击继续(C)。
选中我接受许可协议的条款(A)，单击继续(C)。
选择文件位置，单击立即安装(I)。
安装位置默认为 C:\Program Files\Microsoft Office Servers，搜索索引文件位置默认为 C:\Program Files\Microsoft Office Servers\16.0\Data。
配置SharePoint Server 2016
选中立即运行 SharePoint 产品配置向导(R)，单击关闭(C)。
在SharePoint 产品配置向导界面，单击下一步(N)。
在弹出的对话框中，单击是(Y)，允许在配置过程中重启服务。
选中创建新的服务器场(R)，然后单击下一步(N)。
配置数据库设置和指定数据库访问账户信息，单击下一步(N)。
由于SharePoint的数据库在本机，所以填写本机的数据库及账户。
在配置数据库设置页面，数据库服务器(S)填写.（表示本机），数据库名称(A)填写 SharePoint_Config；在数据库访问帐户区域，用户名(U)填写 EXAMPLE\administrator，密码(P)填写对应密码。
配置指定服务器场的密码，单击下一步(N)。
设置服务器角色，选择前端，单击下一步(N)。
设置SharePoint管理中心的端口号，单击下一步(N)。
本示例以10000端口号为例，您可以根据实际情况设置端口号。
在配置安全设置区域，选择验证方式为 NTLM。
查看并确认SharePoint配置，单击下一步(N)。
当显示如下所示时，说明SharePoint已配置成功。
配置成功页面显示以下配置结果：
配置数据库服务器：test1
配置数据库名称：SharePoint_Config
宿主管理中心 Web 应用程序：是
管理中心 URL：http://test1:10000/
验证提供程序：NTLM
本地服务器角色：前端
单击 完成 关闭向导并启动 SharePoint 管理中心网站。
在浏览器中输入管理中心URL，即可访问SharePoint的管理中心。
成功访问 SharePoint 管理中心首页后，页面展示以下管理功能模块入口：
应用程序管理：管理 Web 应用程序、创建网站集、管理服务应用程序、管理内容数据库
系统设置：管理此场中的服务器、管理服务器场中的服务、管理服务器场功能、配置备用访问映射
监控：查看问题和解决方案、检查作业状态
备份和还原：执行备份、从备份还原、执行网站集备份
安全性：管理服务器场管理员组、配置服务帐户
升级和迁移：转换服务器场许可证类型、查看产品和修补程序安装状态、查看升级状态
一般应用程序设置、应用程序、Office 365、配置向导
