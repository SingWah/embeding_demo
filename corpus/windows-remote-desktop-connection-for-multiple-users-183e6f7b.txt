# Windows Server多用户远程桌面连接
> https://help.aliyun.com/zh/ecs/user-guide/windows-remote-desktop-connection-for-multiple-users/

Windows Server可以通过以下两种方式实现多用户远程桌面连接：默认模式（支持最多2个会话）和多用户远程桌面模式（通过Remote Desktop Services配置支持多用户会话）。通过配置远程桌面服务（Remote Desktop Services），可以满足您在不同场景下的多用户远程桌面连接需求。
远程桌面连接的工作模式
模式一：默认模式
Windows Server默认支持基于RDP（Remote Desktop Protocol）的远程桌面连接，允许最多两个用户同时远程连接到服务器，无需额外配置授权服务或购买许可证（RDS CAL）。同一用户在默认情况下仅能同时建立一个RDP会话，如果已有会话时建立新的会话，会断开之前的会话。如果需要创建新用户进行远程连接，请参见添加更多用于远程连接的用户。
模式二：多用户远程桌面模式
若需要支持多个用户（不限制数量）同时进行远程桌面访问，需要在实例中安装并配置远程桌面服务（Remote Desktop Services, RDS）。
重要
在安装RDS后，可以免费试用120天。在此期间，可以临时支持无限制数量的远程桌面会话。免费试用结束后，必须配置授权服务并安装远程桌面访问许可证（RDS CAL），否则无法进行远程连接并提示以下错误“由于没有远程桌面授权服务器可以提供许可证，远程会话被中断。”
阿里云ECS不提供RDS CAL，您需要从微软官方单独购买并配置。详情请参见为Windows Server实例激活远程桌面服务（RDS）许可证。RDS CAL提供两种授权模式，您可以根据需求进行选择：
每设备模式（Per Device）：按设备授予许可证，每台访问服务器的设备都需要独立的CAL。适用于设备数量少、设备共享的场景，例如固定办公室或工作站。
每用户模式（Per User）：按用户授予许可证，每个用户只需一个CAL，不限制访问设备数量。适用于用户数固定但设备数较多场景，例如远程办公或设备频繁切换。
使用案例
某公司研发部门有一台Windows Server系统的ECS实例，用于运行内部设计软件和存储相关数据。员工平时需要通过远程连接访问该服务器协同办公。
默认模式
刚开始在Windows Server的默认模式下，大家发现系统最多只能支持两名员工同时远程访问该服务器，这远远不能满足日常办公需求。
配置远程桌面服务
技术工程师通过配置远程桌面服务之后，所有员工都可以同时进行远程桌面连接，具体请参见配置Windows多用户远程桌面连接。
遇到远程会话中断问题
经过一段时间使用，员工有一天在正常远程连接该服务器时，系统提示“没有远程桌面授权服务器可以提供许可证，所有远程会话被中断”。此时寻求技术支持后才发现是因为配置的远程桌面服务超过了免费试用期限120天。
问题解决
为了能够实现多用户长期使用，公司最终购买了20个按用户的RDS CAL并完成激活配置，员工可以正常进行远程桌面连接。具体请参见为Windows Server实例激活远程桌面服务（RDS）许可证。
当然如果最多支持2个远程连接会话数也能满足办公要求，则只需删除远程会话服务恢复系统至免费的默认模式即可，具体请参见通过远程桌面连接Windows实例提示“没有远程桌面授权服务器可以提供许可证”错误怎么办？章节中的方案一。
