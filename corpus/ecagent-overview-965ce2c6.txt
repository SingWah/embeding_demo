# 弹性计算 Agent 的功能特性、应用场景、使用限制和计费方式
> https://help.aliyun.com/zh/ecs/user-guide/ecagent-overview

弹性计算 Agent（Elastic Compute Agent，简称 ECAgent）是阿里云推出的智能运维 Agent，支持智能问答、资源查询、异常诊断、健康巡检等核心能力，并提供定时任务、IM 渠道等运维协同能力，帮助您统一管理 ECS、容器等资源。您可通过控制台会话，或钉钉、企业微信、飞书等 IM 渠道，以自然语言快速查询实例状态、诊断异常、执行巡检任务，显著提升运维效率与响应速度。
说明
核心能力
弹性计算 Agent 通过智能会话与定时任务两种模式，为您提供覆盖运维场景的能力。
智能会话
通过自然语言对话，一站式完成资源查询、异常诊断、健康巡检等运维任务，包含以下四大核心能力：
智能问答：基于官方知识库和 RAG 检索，回答ECS产品使用咨询、最佳实践、报错解释等问题。
资源查询：通过自然语言查询 ECS 实例信息、配置、状态等，Agent 会调用资源中心或 OpenAPI 返回结构化结果。
异常诊断：针对 ECS 远程无法连接、卡死、存储性能异常、Web 服务无法访问等常见问题，Agent 通过多源数据关联进行深度诊断，定位根因并给出修复方案。
健康巡检：对 ECS 实例（含 GPU 实例）批量执行健康检查，支持一次性巡检或通过定时任务周期性执行，异常自动通知 IM 渠道。
定时任务
您可以基于官方模板创建定时任务，实现资源健康巡检、资源统计分析等周期性运维工作的自动化执行：
官方模板：开箱即用的标准化模板，如 GPU 资源健康巡检、ECS 资源分析等。
周期调度：支持按小时、天、周及自定义 Cron 表达式自动执行。
结果推送：巡检结果可自动推送至指定 IM 渠道。
IM 渠道
支持配置钉钉、飞书、企业微信 IM 渠道机器人，将 Agent 能力延伸到 IM 场景：
多平台支持：钉钉、飞书、企业微信。
群内协同：机器人入群，运维过程团队可见。
随时随地：手机、PC 端均可发起运维对话。
告警闭环：告警推送到群，群内 @机器人诊断，确认后执行修复。
应用场景
对话式资源操作
痛点：传统控制台操作路径深、字段多，跨地域批量操作需反复切换页面。
方案：您通过自然语言下达指令，例如"统计账号下ECS 资源总核数及地域分布"，Agent 自动完成多地域资源查询、基于地域维度进行核数统计。同样的可以对内存、磁盘、系统监控指标进行分析统计。
价值：操作从"多步点击"简化为"一句话"，显著降低运维门槛与操作失误率。
GPU 集群定时健康巡检
痛点：GPU 集群规模大、训练任务长，异常若发现不及时将导致训练中断。
方案：配置"GPU 集群健康巡检"定时任务，每日或每数小时自动批量巡检 GPU 实例，异常自动推送到 IM 群。
价值：巡检覆盖率从人工抽检提升至 100%，故障从"事后发现"变为"提前预警"。
IM 渠道故障诊断
痛点：传统故障处理需登录控制台逐层排查，值班人员响应链路长。
方案：告警推送到钉钉、飞书运维群后，成员直接 @机器人，Agent 在群内实时展示诊断进度、定位根因。
价值：从发现到修复全程在 IM 内闭环，无需登录控制台。

计费说明
弹性计算 Agent 采用 Credits（积分）作为计费单位，按 Agent 实际消耗的算力资源计费，包含按量付费和资源包两种计费方式。
开通即用：无需订阅、无预付门槛，登录控制台即可使用。
按量付费：按 Credits 实际消耗计费，账单周期结算。
资源包：支持预购 Credits 资源包，享受更优惠的单价。
用量查询：控制台左下角 设置 > 用量与限额 可查看 Credits 用量与剩余额度。
详细计费规则、Credits 消耗逻辑、账单示例，请参见计费方式。
名词解释
术语
说明
弹性计算 Agent
阿里云面向 AI 时代打造的智能化运维产品，基于 Multi-Agent 架构，通过自然语言对话完成 ECS 及相关计算资源的查询、诊断、巡检与运维操作。
会话
用户与 Agent 之间的一次自然语言对话过程，包含多轮问答。
任务
Agent 后台执行的运维作业，当前对外开放定时任务（周期性执行）。
Credits
Agent 的计费单位，Agent 每次调用大模型和工具消耗一定的 Credits。
智能问答
会话能力之一，用于回答云产品使用咨询、报错解释等问题。
资源查询
会话能力之一，用于查询实例信息、配置、状态等资源数据。
异常诊断
会话能力之一，用于对 ECS 常见异常进行深度诊断，定位根因并给出修复建议。
健康巡检
会话能力之一，用于对 ECS 实例（含 GPU 实例）批量执行健康检查。
IM 渠道
Agent 与 IM 平台（钉钉、飞书、企业微信）的集成通道，用于将 Agent 能力延伸到 IM 场景。
弹性计算 Agent 服务关联角色
Agent 访问其他云产品资源所需的 RAM 角色，名称为 AliyunServiceRoleForECAgent。
