# 如何通过控制台购买并使用Linux系统实例？
> https://help.aliyun.com/zh/ecs/user-guide/purchase-a-linux-instance-and-deploy-bt-panel-from-the-console

宝塔面板是图形化服务器管理工具。通过 ECS 自定义购买 Linux 实例并部署宝塔面板，一键安装 LNMP 环境并验证 Web 服务访问。
操作步骤
请保证账号已完成实名认证，且阿里云账户余额（即现金余额）与代金券的总额不低于100.00元人民币的情况下执行以下操作。
重要
完成实名认证的云服务器ECS新用户，可免费试用ECS 3个月，详细限制参见云服务器ECS试用攻略。
步骤一：创建ECS实例
访问ECS控制台-实例，单击创建实例。
选择自定义购买，完成购买配置。
配置示例值可供参考，未提及配置项按照默认即可。
配置项
配置示例值
付费类型
按量付费
地域
华南2（河源）
网络及可用区
专有网络：默认专有网络
交换机：选择可用区B的默认交换机。
实例
ecs.e-c1m1.large
为保证流畅运行，建议实例规格不低于2 vCPU 2 GiB。
镜像
选择公共镜像下Alibaba Cloud Linux 3.2104 LTS 64位。
系统盘
类型：ESSD Entry
容量：40 GiB
公网IP
勾选分配公网 IPv4 地址。
带宽计费模式
按使用流量
建议升级至CDT计费，升级后赠送220GB/月公网流量 （中国内地地域20GB/月，非中国内地200GB/月）。
安全组
选择新建安全组。
登录凭证
选择创建后设置。
确认配置费用，阅读并勾选服务协议，单击确认下单。
步骤二：连接ECS实例
返回实例列表，待实例状态为运行中，且健康状态为正常后，单击操作列的远程连接。
在对话框中，单击通过Workbench远程连接对应的立即登录。
选择免密连接后，单击登录。
远程连接会话最久维持6个小时，如果超过6小时没有任何操作，连接会自动断开，需要重新连接。
看到命令行即表示连接成功。
步骤三：安装宝塔面板
安装宝塔 Linux 面板。
以安装宝塔Linux面板 9.0.0为例。
url=https://download.bt.cn/install/install_lts.sh;if [ -f /usr/bin/curl ];then curl -sSO $url;else wget -O install_lts.sh $url;fi;bash install_lts.sh ed8484bec
根据提示输入y，并回车确认。
获取宝塔 Linux 面板登录信息。
安装完成后，终端将输出面板账户登录信息，其中：
外网面板地址：格式为 https://<公网IP>:<端口>/<安全入口>。记录<端口>，后续放行宝塔面板端口时需要使用。
username：面板用户名。
password：面板密码。
步骤四：放行宝塔面板端口
返回实例列表，单击目标实例 ID 进入实例详情页。
单击安全组页签后，单击安全组 ID。
在入方向页签下，单击增加规则。
配置项
值
授权策略
允许

1

自定义 TCP
访问来源
输入允许访问的公网IP地址。
重要
若使用0.0.0.0/0，表示允许任意 IP 访问远程服务端口，存在安全风险，请谨慎使用。
访问目的（本实例）
步骤三获取的外网面板地址的<端口>。
单击提交。
步骤五：登录宝塔面板并安装 Web 服务
以宝塔Linux面板 9.0.0为例。
登录宝塔面板。
在浏览器中输入步骤三获取的外网面板地址。
首次访问会提示连接不是私密连接，单击高级 > 继续前往即可。
输入步骤三获取的用户名及密码后，单击登录。
阅读并勾选协议后，单击进入面板。
绑定宝塔官网账号，未注册则需先完成注册。
在此注册的账号用于用户登录宝塔会员中心，不可用于宝塔面板的登录。
绑定后，可在弹出的推荐安装套件中，按需选择软件，一键安装。
安装并验证 Web 服务。
以安装 LNMP 为例。
单击 LNMP 选框中的一键安装。
安装完成后，在左侧导航栏单击网站 > 添加站点。域名填写为 ECS 公网 IP，其他保持默认，单击确定。
ECS公网IP可在实例列表的IP地址列获取。
依照步骤四操作，放行80端口。
在本地浏览器访问 http://<ECS公网IP>，页面显示"恭喜, 站点创建成功！"即表示部署完成。
计费说明
计费项
系统盘容量费用：40 GiB（云盘容量） × 云盘单价 × 计费时长。
公网带宽计费（按流量计费）：出网流量 x 每 GB 流量单价。
升级至CDT计费后，将赠送220GB/月公网流量 （中国内地地域20GB/月，非中国内地200GB/月）。
实例规格的计算资源费用：实例规格单价 × 计费时长。
可通过配置报价器查看价格明细。
获取费用明细
登录费用与成本控制台，选择账单 > 账单详情。在产品名称筛选框中选择产品名称云服务器ECS，获取费用明细。
资源清理
使用完毕后可释放实例，停止计费。
重要
释放后数据不可恢复。
在实例列表，单击目标实例操作列下的 > 实例状态 > 释放。
选择立即释放，单击下一步。
确认无即将保留的关联资源信息后，单击确认。
